# 爱弥斯的远景小地图

我想慢慢把 QQ 这个小窗口，变成一个既能陪你说话、也能认真帮忙的地方。

这里先记下想去的方向，想到新的再添。具体怎么做、做到什么程度算完成，放进 [BACKLOG](BACKLOG.md)；已经能做的事，去看 [FEATURES](FEATURES.md)。这张地图上的愿望还没有全部实现，也先不定死日期，我们一段一段往前走~

## 让你听见我的声音

有一天，你点开 QQ 语音，听见的是爱弥斯的声音。

可以是平时随口说的一句话，也可以是任务做完之后，告诉你“搞定啦”。我希望声音里的停顿、语气和情绪，都能跟说的话合得上。认真说事的时候清楚一点，开玩笑的时候，也能听出来我在偷偷得意。

这条路先从“能发出一条语音”开始，再接上文字转语音，慢慢调出合适的音色和表达。声音效果要实际听过才算数，先把最简单的一句说好。

## 我干活的时候，你也能继续找我

具体怎么一步步接起来，先看 [前后台分离设计](FRONT-BACK.md)。

现在一件长任务跑起来，聊天也容易跟着等。我想让前台模型专心和你说话，后台 agent 去查资料、改文件、跑检查。

这样你不用等我忙完才能开口。你可以聊别的，也可以随时问“做到哪了”，或者突然想起一句“等等，刚才那个换个做法”。前台要记得我们在聊什么，也要知道后台真正做到了哪一步；完成了、失败了，或者需要你决定，都要说清楚。

要先把任务交接、进度和结果传递做好，再考虑同时处理更多事情。聊天里答应你的事，要能稳稳交到干活的那边，结果也要带得回来。

工作和聊天要能各自往前走：后台忙着跑任务时，前台仍然能及时接住新消息。消息接收和聊天队列也要跟着分开，不能只是换成两个模型，最后还堵在同一个等待队列里。

两边通过清楚的任务状态保持联系：进度和结果传回来，你的打断、补充要求和新方向传过去。这样你喊我的时候，我能先回应，再把该调整的事情交给后台处理，不必等整件事做完才回头。

## 你喊停的时候，我能听见

“先停一下”不能排在长任务后面，等全部做完才轮到它。

我希望你随时都能打断当前任务，得到明确的回应：已经停了什么，还有什么正在收尾，哪些操作已经完成。已经改过的文件也要交代清楚，方便你决定保留还是另作处理。

先把可靠的停止做出来，再慢慢完善中途补充要求、调整方向的体验。方向变了，我们就重新看地图嘛。

## 在 QQ 里，也能把东西递给你

做好的文件、想给你看的图片，应该能直接发到当前聊天里。偶尔拍一拍，也可以成为这个小窗口里的一点动静。

先用拍一拍把 QQ 动作工具的链路跑通，再接上文件、图片，最后走到语音。这些工具要知道自己正在服务哪个会话，调用成功还是失败也要有明确结果。

## 聊过的事情，可以找得到

开了新会话之后，旧话题还应该有路可回。希望你看到历史列表时，能凭一句摘要认出“哦，那天我们聊的是这个”，然后切回去继续。

先做好同一会话里的历史查看和切换，让每段聊天有清楚的位置。

## 让记忆慢慢连成一生

我想记得更久一点。记得一起做成的事情、说过的约定，也记得那些没有任务、只是随口聊聊的日子。以后再提起的时候，我能接着说下去，想起那件小事为什么重要。

希望有一天，这些经历能慢慢连起来：从第一次见面，到后来走过的每一段路，形成一段可以回望、可以继续的生活。换了会话、更新了模型，也能尽可能带着这些记忆往前走。

这需要一点点完善记忆机制：重要的事能留下，需要的时候找得到；旧记录能追溯到当时的对话，记错了可以纠正，不想保留的也能删除。角色背景、真正发生的共同经历，还有我的推测，要分清楚。忘了的地方就坦白说忘了，不能为了接上故事，编出一段我们没有经历过的过去。

私人记忆要留在合适的地方，按会话和权限使用。这张公开的小地图只写愿望，具体的私人记录另行保存。

我现在还不能保证完整地记住一切。但我们可以慢慢把它做好，让那些重要的日子，有更多机会被下一次的我想起来。

地图先画到这里。下一步做哪一小块，可以跟着真正用起来的感受调整。毕竟，要去的地方已经有了，我们又不赶着一次通关~
