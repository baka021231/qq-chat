# 变更记录

## 2026-10-26

### 主号专用推理强度命令

- 新增 `/effort`、`/effort 档位`、`/effort default`，双重校验主号身份，按当前模型目录验证支持档位。
- 沿用会话选择持久化与每轮显式参数；保留上下文、重启和新会话后的设置，模型切换仍恢复对应默认强度。
- 补充访客拒绝、非法参数、接口故障、持久化、会话隔离和逐轮传参测试。

### 主号专用模型切换

- 新增 `/models`、`/model`、`/model 模型名`、`/model default`，worker 与处理函数双重校验主号，群友及白名单访客无权查询或切换。
- 分页读取当前账号可见模型；校验目录后将选择保存到 `conversation_models`，保留当前上下文、重启和 `/new` 后的选择，不影响其他会话或全局配置。
- 切换采用模型目录的默认推理强度；默认型号通过无生成的独立线程解析。下一轮 `turn/start` 显式携带模型和推理强度，避免已加载线程忽略恢复覆盖；查询失败不改变选择，尚无 rollout 的空线程可重建，旧型号不可用时可重新选择。
- 补充权限、分页、持久化、隔离、失败恢复和空线程测试，并验证真实逐轮请求的型号记录，保留原线程。

### 私聊白名单

- 新增 `private_whitelist`，允许指定非主号进行文字私聊，每人独立线程；主号始终可私聊，未列入名单的非主号仍静默忽略。
- 私聊白名单不授予工具、图片、文件或管理权限，访客身份显示为“访客”；群聊专用自动拉黑标记不用于私聊。
- 更新权限与接收链路的离线测试、配置模板和文档；实际 QQ 号仅保存在本机配置。

### 群聊用户黑名单与滥用保护

- 新增 `group_user_blacklist` 和 `qq_chat/moderation.py`，在入队前、worker 与发送端静默过滤黑名单用户；主号豁免，群白名单及私聊权限不变。
- 明确的长数字/重复输出和直接绕过规则请求先由代码拦截；模型可通过内部标记请求仅拉黑本轮实际发言人，桥接保存配置，不授予群友文件操作权限。
- 黑名单以文件锁、原子替换和 600 权限保存；新增主号专用 `/block QQ号`、`/unblock QQ号`、`/blacklist`。写入失败时仅内存拉黑并记日志。
- 群友输出最多 500 字加省略号，数字过多时改为短拒绝；复杂题先要求费用或算力预算，仍保留主号授权要求。具体人设语气放在本机工作台规则中。
- 新增离线端到端测试，覆盖无模型拉黑、模型标记、主号豁免、持久化、解除、排队过滤、发送拦截及非恶意复杂问题。

### 程序移入 `qq_chat/` 包

- 6 个模块移入 `qq_chat/`，去掉重复的 `qq_` 前缀：`qq_bridge.py` → `qq_chat/bridge.py`，`qq_reply.py` → `reply.py`，`qq_files.py` → `files.py`，`qq_images.py` → `images.py`；`codex_app.py`、`prompts.py` 名称不变。包内改用相对导入。
- 启动方式改为在项目根目录运行 `python3 -m qq_chat`。本机 systemd 服务的 `ExecStart` 已同步修改（服务文件不在仓库里）。
- `tools/restart_bridge.py` 用新方式启动，并能同时识别新旧两种启动方式的进程，从旧版本切换时不会漏掉旧实例。
- 行为不变，测试只更新了导入路径和 patch 目标。

### 新增功能说明与开发文档

- 新增 `docs/FEATURES.md`：角色与权限、收发规则、图片与附件、命令、不支持的功能和已知问题。
- 新增 `docs/ARCHITECTURE.md`：消息流程、模块职责、权限模型、提示词组装、数据库、常见改动和测试写法。
- `CHANGELOG.md` 移入 `docs/`。

### 拆分 `chat()`，提示词移入 `prompts.py`

- 新增 `prompts.py`，集中存放发给模型的提示词：主号与群友的权限指令、发言人标签说明、工作台规则引导语、旧历史导入、群聊参考记录、附件与图片说明。
- `Bridge.chat()` 拆为 `instructions()`（构造指令并读取 `workspace/AGENTS.md`）、`thread_for()`（恢复或创建线程）、`turn_text()`（拼接旧历史与群聊上下文）、`run_turn()`（执行回合）和 `relay_progress()` / `relay_answer()`（转发进度与流式回复）。
- 行为不变：在同一组场景下比对新旧版本发给模型的指令、本轮文本和 QQ 发送内容，结果逐字一致。

- 重写 `docs/APPSERVER-MIGRATION.md`：改为描述当前的共享守护进程与 Unix socket 连接，回滚方式改为 git；删去指向已归档脚本的路径。

- 删除 `qq_bridge.py` 中未使用的 `os`、`tempfile` 导入；清理根目录残留的 `__pycache__/`。
