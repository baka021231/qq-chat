## 2026-10-26

### 身份称呼统一

- 统一代码提示、管理命令说明、文档与工作台规则中的身份称呼为“主人”；QQ 号校验、配置字段和权限逻辑不变。

### 主人资料按身份加载

- OWNER.md 仅在已核验主人的私聊或群内独立操作会话中读取并注入；SOUL.md 仍用于所有会话。
- 本地工作台规则拆分为人设与交流（SOUL）、主人资料（OWNER）、操作及开发约束（AGENTS），拆分前保留本地备份，私人文件不纳入 Git。
- 验证主人私聊、群聊能加载资料，群友及私聊访客不加载；旧线程历史不会自动清除。

### 分离桥接设定与原生规则

- 桥接每轮依次加载 workspace/SOUL.md、OWNER.md，不再读取或手动注入 AGENTS.md；后者保留 Codex 原生加载。
- 缺失设定文件跳过，不自动创建或迁移，不回退读取 AGENTS.md；主人和访客均保持现有权限控制。
- 更新文档并验证双文件注入、热更新、缺失文件及不注入 AGENTS.md。

### 随机回复间隔

- 统一发送限速从固定 1.5 秒改为每条随机 2～3 秒，覆盖正文、进度、命令回复和长消息分片。空闲后的首条无需额外等待；实际间隔也受内容生成和网络耗时影响。流式分段空闲超时仍为 1.5 秒。

### 主人专用推理强度命令

- 新增 `/effort`、`/effort 档位`、`/effort default`，双重校验主人身份，按当前模型目录验证支持档位。
- 沿用会话选择持久化与每轮显式参数；保留上下文、重启和新会话后的设置，模型切换仍恢复对应默认强度。
- 补充访客拒绝、非法参数、接口故障、持久化、会话隔离和逐轮传参测试。

### 主人专用模型切换

- 新增 `/models`、`/model`、`/model 模型名`、`/model default`，worker 与处理函数双重校验主人，群友及白名单访客无权查询或切换。
- 分页读取当前账号可见模型；校验目录后将选择保存到 `conversation_models`，保留当前上下文、重启和 `/new` 后的选择，不影响其他会话或全局配置。
- 切换采用模型目录的默认推理强度；默认型号通过无生成的独立线程解析。下一轮 `turn/start` 显式携带模型和推理强度，避免已加载线程忽略恢复覆盖；查询失败不改变选择，尚无 rollout 的空线程可重建，旧型号不可用时可重新选择。
- 补充权限、分页、持久化、隔离、失败恢复和空线程测试，并验证真实逐轮请求的型号记录，保留原线程。

### 私聊白名单

- 新增 `private_whitelist`，允许指定非主人进行文字私聊，每人独立线程；主人始终可私聊，未列入名单的非主人仍静默忽略。
- 私聊白名单不授予工具、图片、文件或管理权限，访客身份显示为“访客”；群聊专用自动拉黑标记不用于私聊。
- 更新权限与接收链路的离线测试、配置模板和文档；实际 QQ 号仅保存在本机配置。

### 群聊用户黑名单与滥用保护

- 新增 `group_user_blacklist` 和 `qq_chat/moderation.py`，在入队前、worker 与发送端静默过滤黑名单用户；主人豁免，群白名单及私聊权限不变。
- 明确的长数字/重复输出和直接绕过规则请求先由代码拦截；模型可通过内部标记请求仅拉黑本轮实际发言人，桥接保存配置，不授予群友文件操作权限。
- 黑名单以文件锁、原子替换和 600 权限保存；新增主人专用 `/block QQ号`、`/unblock QQ号`、`/blacklist`。写入失败时仅内存拉黑并记日志。
- 群友输出最多 500 字加省略号，数字过多时改为短拒绝；复杂题先要求费用或算力预算，仍保留主人授权要求。具体人设语气放在本机工作台规则中。
- 新增离线端到端测试，覆盖无模型拉黑、模型标记、主人豁免、持久化、解除、排队过滤、发送拦截及非恶意复杂问题。
